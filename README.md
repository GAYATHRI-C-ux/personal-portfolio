## 🚀 How to Preview and Deploy

### 1. View it Locally Right Now
In File Explorer, navigate to:
`C:\Users\KGCAS\.gemini\antigravity\scratch\personal-portfolio`
Double-click **`index.html`** to open and test your portfolio in your default browser.

### 2. Push to GitHub
Open Windows PowerShell and run:
```powershell
cd C:\Users\KGCAS\.gemini\antigravity\scratch\personal-portfolio
git init -b main
git add .
git commit -m "feat: complete Dark Bento Grid portfolio for Gayathri C"
git remote add origin https://github.com/GAYATHRI-C-ux/personal-portfolio.git
git push -u origin main
```

### 3. Deploy to Vercel (100% Free)
1. Go to [vercel.com](https://vercel.com/) and sign in with your GitHub account.
2. Click **"Add New..."** → **"Project"**.
3. Import your `personal-portfolio` repository and click **"Deploy"**.
4. Your portfolio will go live with an instant SSL URL (e.g. `gayathri-portfolio.vercel.app`).
