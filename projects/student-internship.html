Original Java Source Code
InternshipSystem.java
import java.util.Scanner;

class Internship {
    String name;
    String company;
    String role;
    String status;
}

public class InternshipSystem {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);
        Internship s = new Internship();
        int choice;

        System.out.println("----- STUDENT INTERNSHIP SYSTEM -----");

        // Input student details
        System.out.print("Enter Student Name: ");
        s.name = sc.nextLine();

        System.out.print("Enter Company Name: ");
        s.company = sc.nextLine();

        System.out.print("Enter Role: ");
        s.role = sc.nextLine();

        // Initial status
        s.status = "Pending";

        // Display application
        System.out.println("\n--- Application Submitted ---");
        System.out.println("Name    : " + s.name);
        System.out.println("Company : " + s.company);
        System.out.println("Role    : " + s.role);
        System.out.println("Status  : " + s.status);

        // Admin decision
        System.out.println("\nAdmin Review:");
        System.out.println("1. Approve");
        System.out.println("2. Reject");
        System.out.print("Enter choice: ");
        choice = sc.nextInt();

        if (choice == 1) {
            s.status = "Approved";
        } else {
            s.status = "Rejected";
        }

        // Display updated status
        System.out.println("\n--- Updated Status ---");
        System.out.println("Final Status: " + s.status);
        System.out.println("\nThank You!");

        sc.close();
    }
}
Java Concepts Used in This Project
🧱
Class & Object
Internship class acts as a blueprint; s is the object instance that holds actual data.
📋
Instance Variables
name, company, role, and status are fields on the Internship object.
⌨️
Scanner (I/O)
Scanner reads user input line-by-line (nextLine()) and integers (nextInt()) from stdin.
🔀
Conditional Logic
if-else evaluates the admin's integer choice to set the final status to Approved or Rejected.
🖨️
System.out.println
Standard Java console output prints application details and updated decision to the terminal.
📦
Static Main Method
Program entry point — public static void main(String[] args) is where JVM begins execution.
